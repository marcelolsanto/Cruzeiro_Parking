# ProjetoInterdisciplinarIII# Cruzeiro Parking

## Descrição

Cruzeiro Parking é um projeto interdisciplinar desenvolvido pelo grupo Cruzeiro do Sul. Este sistema tem como objetivo gerenciar um estacionamento, permitindo operações como cadastro de veículos, controle de vagas, e emissão de relatórios.

## Tecnologias Utilizadas

- **Linguagem:** C#
- **Framework:** .NET
- **Arquitetura:** MVC (Model-View-Controller)
- **Banco de Dados:** [Especificar se houver]

## Estrutura do Projeto

O projeto está organizado nas seguintes pastas:

- **Controller:** Contém os controladores que gerenciam a lógica de negócios e interagem com o modelo e a visão.
- **Model:** Define as classes que representam os dados e a lógica de negócios.
- **View:** Contém os arquivos relacionados à interface do usuário.
- **Properties:** Arquivos de configuração e recursos do projeto.
- **Resources:** Recursos adicionais, como arquivos de configuração e imagens.

## Funcionalidades Principais

- **Cadastro de Veículos:** Permite o registro de veículos no sistema.
- **Controle de Vagas:** Gerencia a disponibilidade de vagas no estacionamento.
- **Emissão de Relatórios:** Gera relatórios sobre o uso do estacionamento.
